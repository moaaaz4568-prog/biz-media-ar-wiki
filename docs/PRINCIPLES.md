# Principles — the non‑negotiable rules and why each exists

Every rule here exists to stop a specific failure that kills ad‑hoc “summarize my files” attempts.

| Principle | Why it exists (the failure it prevents) |
|---|---|
| **Everything enters whole** | Pre‑filtering “good” vs “bad” content loses real, useful minority views and bakes the editor’s bias into the base. |
| **Show both sides (tensions)** | Silently picking one of two conflicting facts produces a confident, wrong knowledge base. |
| **Source is a read‑only witness** | If you edit the source, nothing can later prove a summary wrong. The source is the only ground truth. |
| **No claim without a source** | “Expert” text that can’t be traced to a quote is indistinguishable from hallucination. |
| **Move, never delete** | Bulk deletes are irreversible and have wiped whole knowledge bases. Moving to `archive/` is reversible. |
| **Measure, don’t assert** | A number with no command behind it is a guess. Prefer a count you can re‑run; if you must estimate, label it an estimate. |
| **Concepts before masters** | Building the “expert” file before the raw knowledge exists produces an empty, impressive‑looking shell. |
| **Naming is the query** | A wrong prefix or folder breaks search structurally, not just cosmetically. One type = one prefix = one folder. |
| **Every gate must be able to fail** | A check that always passes is worse than no check — it turns an error into “verified.” Test each gate with a known‑bad case. |
| **A machine can’t see intent** | A formula with a fake “when it breaks” line passes automated checks. Human review of the key sections is required. |

## The anti‑“dead recipe” test
A master’s advice must survive this test: *would it still help a thousand people who never read the source and don’t know they are repeating it?* If a recipe (a) names the output not the action, (b) has no condition that distinguishes when it applies, (c) has no counter‑case that would break it, and (d) produces no different result — it is a “dead recipe”: true but useless. Cut it.

## What is left to the human (never decide these yourself)
- Where exactly the line is between an off‑topic/low‑value item and a legitimate minority view.
- Whether conflicting pages are merely shown side by side, or flagged further.
- Any security action (rotating a leaked key, making a repo public).
